Sobre o Projeto

Conheça o YGO São Luís e os objetivos deste projeto.

O que é o YGO São Luís?

O YGO São Luís é um sistema desenvolvido para reunir e divulgar informações sobre os torneios de Yu-Gi-Oh! realizados em São Luís, Maranhão.

A plataforma busca facilitar o acesso da comunidade a informações sobre eventos, jogadores, rankings, decks, resultados e notícias relacionadas ao cenário local.

Objetivo

O objetivo do projeto é contribuir para a organização e divulgação do cenário competitivo local, oferecendo um espaço centralizado para consulta de informações e estatísticas dos torneios.

Público-alvo

O sistema é destinado a jogadores de Yu-Gi-Oh!, organizadores de torneios, lojas de card games e demais integrantes da comunidade de jogos de cartas colecionáveis de São Luís.

Atividade Extensionista

O projeto foi desenvolvido como atividade extensionista do curso de Análise e Desenvolvimento de Sistemas, buscando aplicar conhecimentos de desenvolvimento web na criação de uma solução voltada para uma comunidade local.
